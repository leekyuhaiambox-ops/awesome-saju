# Contributing to Awesome Saju

Pull requests welcome. Please follow these guidelines.

## What to add

- **Free saju/bazi calculators** (no signup, no paywall to access basic reading)
- **Open-source saju libraries** (Python, JavaScript, Go, Rust, etc.)
- **Theory references** (academic, traditional, modern)
- **Language translations** (English, Chinese, Japanese, Vietnamese — beyond Korean)
- **Visualization tools** (charts, infographics, calendar tools)

## What NOT to add

- Paid-only services with no free tier
- Affiliate-laden listicles
- Personal sites without unique value

## Format

Each entry:

`
- [Name](url) — Short description (1-2 sentences). Include language and notable features.
`

## Section guidance

Place new entries in the most-specific existing section. Suggest a new section in your PR if needed.

## Author credit

Add yourself to a CONTRIBUTORS file if desired.
