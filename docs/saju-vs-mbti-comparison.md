# Saju vs MBTI — Complete Comparison

Two personality typing systems often compared in Korea. This document compares them on 8 dimensions.

| Dimension | MBTI | Saju Day Pillar |
|---|---|---|
| Type count | 16 | 60 |
| Foundation | Self-report questionnaire (~93 questions) | Birth date + time (astronomical calculation) |
| Time to result | 20 minutes | 5 seconds |
| Change over time | Can change with life stage | Permanent (set at birth) |
| Statistical validation | Moderate test-retest reliability | None (traditional knowledge) |
| Granularity | 16 types = ~510M people per type globally | 60 types = ~133M people per type globally |
| Cultural origin | 20th century USA (Carl Jung-derived) | East Asia, 2000+ years |
| Cost | Free online tools, paid official | Free online, paid traditional readers |

## When to use which

**MBTI**: when you want a snapshot of *current* preferences (introversion/extroversion etc.). Useful for team-building, current job fit.

**Saju Day Pillar**: when you want a lifelong *temperament* map. Useful for self-understanding, long-term life patterns, traditional decision-making frameworks.

**Both**: complementary. MBTI shows present surface, saju shows underlying nature.
